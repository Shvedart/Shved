# Кэшбэки и бонусы — прототип онбординга новичков

Интерактивный мобильный веб-прототип по макету Figma (файл `0lPBqwZ8FmDWRcFUVXPxFF`, секция «new people»). Работает в браузере телефона и как PWA с домашнего экрана. Сборки нет: чистые ES-модули и CSS.

## Быстрый старт

Нужен только Python 3 (на macOS уже есть; проверить — `python3 --version`).

```bash
cd "K&B-new people"
python3 tools/serve.py
```

Откройте http://localhost:5178 — лучше в режиме телефона (DevTools → Device toolbar, 375×812).

**С телефона:** телефон и компьютер в одной Wi‑Fi сети → на телефоне `http://<IP-компьютера>:5178` (IP на Mac: «Системные настройки → Wi‑Fi → Подробнее» или `ipconfig getifaddr en0`).

- **PWA на iPhone:** Safari → «Поделиться» → «На экран „Домой“». Service worker работает только по HTTPS или на `localhost`; для полноценной установки с телефона нужен HTTPS (туннель или любой хостинг статики).
- `?nosw` в адресе отключает service worker — удобно, если телефон показывает старую версию.

## Что внутри

Три сценария на разводящей:

1. **01 — онбординг через лайк оффера**: 5 шагов, выбор категорий ПК, главная «Кэшбэк».
2. **02 — онбординг через лайк бренда**: то же, но лайкают бренды.
3. **03 — заход через хук и упущенную выгоду**: главная с плашкой «могли получить ещё +512 ₽» → тур по экрану (серия 5 дней, карточка-«прожектор» с бейджем «Активен», скретч-карточка, лайки, финал).

Подробная карта экранов и переходов — `docs/SCENARIOS.md`.

## Структура

```
index.html, manifest.webmanifest, sw.js   оболочка и PWA (кеш оболочки — список SHELL в sw.js)
cashback-web.json                         исходные офферы (как прислали)
data/overrides.json                       бренды, тексты, подборки, серия, доп. оффер
styles/tokens.css                         дизайн-токены: цвета, радиусы, отступы, шрифты, движение
styles/base.css | components.css | screens.css
src/core/      router (стек страниц, переходы), store (состояние + localStorage), haptics, motion, dom (h(), иконки)
src/data/      repository — источник данных (локальный JSON или API с тем же контрактом)
src/domain/    catalog — модель «категория → бренд → офферы», форматирование подписей
src/ui/        appbar, компоненты (строки, чипсы, карточки, сердце), «Мое любимое», скретч-карточка, тосты, шторка
src/screens/   hub, bank, onboarding, main, tour (тур сценария 03), pk, offer, favorites
assets/        иконки (SVG), картинки, видео короны для скретч-карточки, иконки PWA
design-ref/    эталонные скриншоты фреймов Figma
docs/SCENARIOS.md                         карта сценариев и принятые допущения
tools/serve.py                            локальный сервер без кеширования
```

Чтобы подключить API, передайте в `loadCatalog` свой источник (см. `createApiSource` в `src/data/repository.js`) — экраны менять не нужно.

## Что сохраняется

| Данные | Поведение |
|---|---|
| Избранные бренды, выбранные категории, пройденный онбординг, день серии, пройденный тур | хранятся в `localStorage` (`kb-new-people:v1`) |
| Текущий экран и шаг | восстанавливаются из адреса |
| Возврат на разводящую | **сбрасывает всё** — каждый сценарий начинается с чистого листа |

## Хаптики

`src/core/haptics.js`: на Android — Vibration API, на iOS 17.4+ — системный тик переключателя (`<input type="checkbox" switch>`). Без поддержки всё работает с визуальной обратной связью.

## Работа с нейросетью

Если продолжаете проект с ИИ-ассистентом (Claude Code, Cursor, Codex и т. п.) — откройте эту папку как проект. Правила для ассистента лежат в `AGENTS.md` (Claude Code читает его через `CLAUDE.md`). Там описано, как устроен код, что уже решено и что проверять после правок.
