# Кэшбэки и бонусы — прототип онбординга новичков

Интерактивный мобильный веб-прототип по макету Figma (секция «new people»). Работает в браузере и как PWA с домашнего экрана.

## Запуск

```bash
python3 tools/serve.py
```

Откройте http://localhost:5178. Сервер слушает все интерфейсы, поэтому с телефона в той же Wi‑Fi сети откройте `http://<IP-компьютера>:5178`.

- **PWA на iPhone:** Safari → «Поделиться» → «На экран „Домой“». Service worker и установка требуют HTTPS или `localhost`; для установки с телефона нужен HTTPS (например, через туннель или хостинг статики).
- `?nosw` отключает service worker, `?swipe` включает свой свайп назад в обычном браузере (по умолчанию он работает только в режиме PWA на iOS).
- Сборка не нужна: чистые ES-модули и CSS.

## Структура

```
index.html, manifest.webmanifest, sw.js   оболочка и PWA
cashback-web.json                         исходные офферы (как прислали)
data/overrides.json                       бренды, тексты, подборки, доп. оффер
styles/tokens.css                         дизайн-токены: цвета, радиусы, отступы, шрифты, движение
styles/base.css | components.css | screens.css
src/core/      router (стек, переходы, свайп), store (состояние + localStorage), haptics, motion, dom
src/data/      repository — источник данных (локальный JSON или API с тем же контрактом)
src/domain/    catalog — модель «категория → бренд → офферы», форматирование подписей
src/ui/        appbar, компоненты (строки, чипсы, карточки, сердце), блок «Мое любимое», тосты
src/screens/   hub, bank, onboarding, main, tour, pk, offer, favorites
design-ref/    эталонные скриншоты фреймов Figma
docs/SCENARIOS.md                         карта сценариев и принятые допущения
```

Чтобы подключить API, передайте в `loadCatalog` свой источник (см. `createApiSource` в `src/data/repository.js`) — экраны менять не нужно.

## Что сохраняется

| Данные | После перезагрузки |
|---|---|
| Избранные бренды | сохраняются |
| Выбранные категории и оценка | сохраняются, изменить нельзя |
| Пройденный онбординг, засчитанный день серии, пройденный тур | сохраняются |
| Текущий экран и шаг (адрес) | восстанавливаются |
| Скролл, шаг тура, подсказка с сердечками | сбрасываются |

«Сбросить прототип» на разводящей очищает всё сохранённое.

## Хаптики

Единый адаптер `src/core/haptics.js`: на Android используется Vibration API, на iOS 17.4+ — системный тик переключателя (`<input type="checkbox" switch>`). Без поддержки всё работает с визуальной обратной связью. Срабатывает на лайке, выборе чипса и категории, звезде оценки, подтверждении выбора и завершении онбординга.
