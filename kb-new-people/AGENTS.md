# Инструкции для ИИ-ассистента

Это кликабельный прототип мобильного раздела «Кэшбэки и бонусы» (Т-Банк) для новичков. Заказчик — дизайнер: правки приходят короткими сообщениями на русском, часто со скриншотами с телефона и пометками. Отвечай по-русски, коротко: что изменено, где, проверено ли.

## Запуск и проверка

- Сервер: `python3 tools/serve.py` → http://localhost:5178 (без кеша, слушает все интерфейсы — открывается с телефона по IP).
- Проверяй в браузере в размере телефона **375×812**. Основные адреса: `#/` (разводящая), `#/main/s1`, `#/main/s3` (главная сценария 03 с туром), `#/onb/s1/1`.
- Состояние в `localStorage` (`kb-new-people:v1`); для чистой проверки — `localStorage.clear()` и перезагрузка. Возврат на разводящую тоже всё сбрасывает.
- Сборки, npm и тестов нет — не добавляй их без просьбы.

## Код и стиль

- Чистые ES-модули без фреймворка. DOM собирается через `h(tag, props, ...children)` из `src/core/dom.js`; кнопки — `button()` (сжатие при нажатии уже встроено).
- Анимации — Web Animations API через `animate()` из `src/core/motion.js` (уважает `prefers-reduced-motion`), кривые — `EASE.ios`, `EASE.spring`, `EASE.out`.
- Цвета, отступы, радиусы, шрифты — токены из `styles/tokens.css` (`--c-*`, `--sp-*`, `--r-*`, `--font-*`). Типографика карточек ленты — классы `.ocard-*`; новое оформляй ими, а не новыми размерами.
- Комментарии в коде — на русском, короткие, объясняют «почему». Держи стиль соседнего кода.
- Иконки: `icon(name)` — монохромная (цвет из `currentColor`), `iconImg(name)` — цветная. Файлы в `assets/icons/<name>.svg`.

## Обязательно после правок

1. **Service worker**: при любом изменении файлов подними `VERSION` в `sw.js` (`kb-np-vN` → `vN+1`), иначе телефон с PWA покажет старую версию. Новый JS/CSS-файл добавь в список `SHELL`.
2. Проверь сценарий в браузере на 375×812 и консоль на ошибки.
3. Коммить только по просьбе заказчика.

## Особенности iOS Safari (уже решено — не ломай)

- **Статус-бар** Safari красит по фону закреплённого элемента у верхнего края, даже прозрачного. Поэтому `#app` белый, а затемнение переходов (`.page-dim`) анимирует `background-color`, а не `opacity`.
- **Иконки** встраиваются в DOM как `<svg>` (`mountSvg` в `dom.js`): Safari растрирует SVG в `mask-image` и `<img>`, и они мылятся.
- **Свайп назад** свой убран — был нестабилен с системным. Назад — только кнопкой в апп-баре.
- Страница получает фокус после перехода (для скринридера) — рамка фокуса у `.page` отключена.

## Тур сценариев 03 и 04 (`src/screens/tour.js`)

Два тура: `TOUR_HABIT` (03, эксперимент: вокруг привычки «перед покупкой загляни сюда» — приветствие → ценность со счётчиком → галочка → сердечко-закладка → стирашка → навигация по категориям → финал) и `TOUR_MECHANICS` (04, исходный: механики по очереди, с шагом про серию). Выбор — `TOURS` по сценарию. Шаги описаны массивами: текст, кнопка (`cta`), подсвечиваемый блок (`target` = `data-tour` на главной) и флаги механики:

- `spotlight` — карточка ленты выезжает в центр (копия поверх страницы), всё остальное скрыто, карточка серая, зелёный бейдж «Активен» с бликом; «Понятно» или скролл возвращают её на место.
- `scratch` — скретч-карточка (`src/ui/scratch.js`) с подсказкой, как стирать; стирать не обязательно, «Далее» доступна сразу.
- `hearts` — подсказка на сердечках, лайк по желанию; `nudgeRows` — докрутка ленты на N рядов.
- `stay` — финал без прокрутки и без затемнения.
- `counter: N` — над текстом шторки число бежит 0 → N, а лента сама прокручивается до середины (`runCounter`); шторка на этом шаге выше обычной (`.tour.is-tall`), число с подписью стоит по центру свободного места.
- `navDemo: [id, …]` — лента встаёт к навигации «Лента выгоды», тур сам по очереди нажимает категории (`.feed-nav-item[data-cat]`) и в конце возвращает всю ленту (`runNavDemo`).
- `hero` — картинка в центре финала: шторка растягивается почти на весь экран, фон — белый градиент; одновременно поверх экрана играет конфетти (Lottie: `assets/lottie/confetti.json`, плеер `assets/vendor/lottie_light.min.js`, модуль `src/ui/confetti.js`; слой с `pointer-events: none`, кнопки под ним нажимаются).

Отметки «просмотрено» (маленькая зелёная галочка в углу логотипа) ставит трекер `trackViews` — когда карточка проходит центр экрана, и после тура тоже. Шторка тура лежит внутри прокручиваемой страницы и прилеплена к низу (`position: sticky`), поэтому свайп по ней листает ленту нативно — отдельный слой поверх страницы на iPhone перехватывал скролл даже с `pointer-events: none`. Перед карточкой-«прожектором» тур ждёт, пока докрутка ленты закончится (`scrollIdle`). Граница «видимой зоны» над шторкой — `sheet.getBoundingClientRect().top + 60`, её надо менять вместе с высотой градиента (`.tour { padding-top }` в `screens.css`).

## Скретч-карточки

5 штук в ленте (`SCRATCH_PRIZES` и `SCRATCH_SLOTS` в `src/screens/main.js`); первая — первая в 8-м ряду, её стирают в туре. Фольга рисуется на canvas: шахматка корон переливается от скролла страницы, при стирании летят кусочки, приз открывается на 65% стёртого.

## Лента полками

Во всех сценариях главная сразу показывает ленту полками; тур сценария 03 проходит уже по ней. Над полками — навигация по категориям с иллюстрациями (макет 654:145600, `NAV` в feed.js, картинки в `assets/img/cats`): тап оставляет только полки категории, повторный тап — вся лента; интерактивная полка в категории идёт второй. Раскладка: `src/screens/feed.js`, массив `LAYOUT` — заголовок, подзаголовок, категория каталога, фильтр по названию и номер скретч-карточки (тогда офферов 3). Карточки не пересоздаются, а переезжают — галочки и стёртые стирашки сохраняются. Остатки идут полками по 4 по категориям и общими «Ещё для вас».
Между полками — «Путешествия» (билет с направлениями, раскрытый, без раскрытия при скролле) и «События для вас» (афиша с параллаксом, закольцована): `src/ui/shelves.js` + `styles/shelves.css`, перенесены из прототипа «parallax афиша» (`feed/components-slow.*`). Размеры у них считаются через `ResizeObserver` — полки строятся до того, как страница попала на экран.

## Промокоды

Отдельная сущность ленты, похожая на оффер (макет 662:145964): голубая плитка, логотип сверху, скидка, условия, перфорация и замаскированный код. Данные — `data/discounts.json` (категория → предложения: `discount`, `promoCode`, `condition`, `date`, `logo`), разбор — `buildPromos` в `src/domain/catalog.js`, карточка — `promoCard` в `src/ui/components.js`. В ленте: в полке без стирашки один оффер уступает место промокоду той же категории; полка `{ kind: 'promos' }` в `LAYOUT` собирает оставшиеся, лишние — в «Ещё промокоды» в конце. Галочки «просмотрено» на промокоды не ставятся.

## «Мое любимое»: два вида

Новый вид `look: 'v2'` (макет 668:149352) — в сценариях 01 и 02, старый `v1` с чипсами — в 03. Какой вид где — таблица `LOOK_BY_SCENARIO` в `src/ui/favcard.js`; старый вид в коде сохранён, вернуть его сценарию — поставить `'v1'`. В v2 вместо чипсов — логотипы брендов 56px с плашкой самого большого кэшбэка (рост — зелёная со стрелкой, замена — красный счётчик), выбранный — со скруглением 8px, остальные с прозрачностью 65%; процент в строке — SF Pro Rounded, 8px до названия. «+» ведёт на экран «Бренды» (`src/screens/brands.js`, `#/brands`: по одному самому жирному офферу каждого бренда, поиск по названию, чипсы категорий, сердечко добавляет бренд в «Мое любимое»).
